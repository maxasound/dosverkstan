# Dosverkstan
Klickbar produktpresentation med ett personligt före- och efterexempel, tre supporterbilder och en dosstudio direkt på startsidan.

## Visa demon
Jämför Max originalfoto med den illustrerade dosan. Välj Prova med ditt foto och testa färgtryck, svartvitt eller fotografi. Prova en tryckfärg, växla mellan dosa och stockomslag eller använd ett eget foto. Välj innehåll, presentutförande och antal stockar. Godkänn sammanställningen för att avsluta demonstrationen. Presentfotot med öppnad dosa och tryckta prillor finns längre ned på sidan.

## GitHub Pages
Ladda upp zip-filens uppackade innehåll i roten av ett GitHub-repo. Välj Settings → Pages → Deploy from a branch → main → / (root). Sidan kan även öppnas direkt med index.html.

## Om demon
Filerna kräver inga API-nycklar eller byggsteg. Fotostudion skapar färgseparerade porträtt lokalt med Canvas. Max-dosan är ett separat AI-illustrerat exempel. Övriga designval sparas för fliken om webbläsaren tillåter det. En motivbeskrivning kan matchas mot förberedda illustrationer. Prilltryck, sortiment och produktionsupplägg är koncept för diskussion. Inga betalningar eller beställningar skickas.
